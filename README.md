# flatten.site

Drop in a ZIP, get a flat file tree or one plain-text blob — for pasting a codebase into an AI context window.

Live: https://flatten.site

Flask app. Set `FLASK_SECRET_KEY` in the environment before running.

```
pip install flask
FLASK_SECRET_KEY=dev python main.py
```

Part of [aithings](https://aithings.online).
